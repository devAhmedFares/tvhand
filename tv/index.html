TV Remote Server

التطبيق المساعد المجاني لـ TVHand، للشاشات الأندرويد الاقتصادية. بيتسطّب على الشاشة مرة واحدة بس.

⬇ تنزيل / Download
  1. دوس تنزيل. لو الشاشة سألت، اسمح بالتثبيت من المتصفح أو من تطبيق Downloader.
  2. افتح الملف TVRemoteServer.apk ودوس تثبيت.
  3. افتح TV Remote Server مرة واحدة.
  4. علشان الماوس: الإعدادات ← إمكانية الوصول ← TV Remote Server ← تشغيل.
  5. افتح TVHand على موبايلك، وهو على نفس الـ Wi‑Fi، وهيلاقي الشاشة لوحده.
English: press Download, open TVRemoteServer.apk and install it (allow installs from this browser or Downloader if asked). Open TV Remote Server once. For the mouse: Settings → Accessibility → TV Remote Server → On. Then open TVHand on your phone on the same Wi‑Fi.

Samsung · LG · Roku · Google TV لا يحتاجوا المساعد ده. / don't need this helper.
